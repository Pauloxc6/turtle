Instalação Rápida

Clone o repositório e inclua o arquivo principal no seu script Shell: 

# Clone o repositório é execute o install.sh
user@db:~$ git clone https://github.com/Pauloxc6/turtle.git turtle
user@db:~$ cd turtle
user@db:~/turtle$ bash install.sh

# Run
user@db:~/turtle$ orm --version
